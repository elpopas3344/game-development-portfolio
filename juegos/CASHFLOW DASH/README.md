# CASHFLOW DASH

## 📝 Descripción
**CASHFLOW DASH** es un juego dinámico enfocado en la gestión rápida de recursos y la toma de decisiones bajo presión de tiempo. 
* **Objetivo:** Administrar los flujos de efectivo y superar los retos financieros antes de que el tiempo se agote.
* **Mecánica principal:** Interacción rápida con la interfaz para equilibrar números y maximizar ganancias.

## 🎮 Género
* Strategy / Arcade

## ⌨️ Controles
* **CLICK / MOUSE:** Interactuar con los elementos de la interfaz y botones de gestión.
* **ESC:** Pausa.
