# MensInBlack

## 📝 Descripción
**MensInBlack** es un trepidante juego de acción y disparos inspirado en temáticas de ciencia ficción y agentes secretos.
* **Objetivo:** Neutralizar las amenazas alienígenas que aparecen en pantalla y sobrevivir el mayor tiempo posible.
* **Mecánica principal:** Movimiento ágil del jugador y disparo de precisión con el ratón.

## 🎮 Género
* Shooter / Acción

## ⌨️ Controles
* **WASD / Flechas:** Movimiento del personaje.
* **MOUSE:** Apuntar.
* **CLICK:** Disparar.
* **ESC:** Pausa.

## 🛠️ Tecnologías utilizadas
* HTML5 Canvas, CSS3 y JavaScript puro.
* Asistencia de IA para la estructuración de la detección de colisiones.

## 🚀 ¿Qué aprendimos?
Controlar el bucle principal de renderizado (`requestAnimationFrame`) y gestionar múltiples elementos en movimiento simultáneo.

## 🔧 Mejoras a futuro
Agregar efectos de sonido envolventes, animaciones de impacto y selección de diferentes tipos de armas.
